# 🎅 Meu Pedido para o Natal

Plataforma web que permite crianças em vulnerabilidade registrarem suas cartinhas para o Papai Noel, com consentimento do responsável.

## 🎯 Objetivo
Resgatar a magia do Natal e criar uma ponte entre crianças em vulnerabilidade e doadores/instituições.

## 🛠 Tecnologias
- HTML5
- CSS3
- JavaScript (vanilla)
- API ViaCEP
- localStorage

## ✨ Funcionalidades
- Validação completa de formulário
- Máscaras de CEP e telefone
- Busca automática de endereço via CEP
- Contador de caracteres da carta
- Exibição das últimas 3 cartas enviadas
- Layout responsivo e acessível

## 🚀 Como executar
1. Clone o repositório
2. Abra `index.html` no navegador

## 📱 Responsivo
Funciona em desktop, tablet e celular.
