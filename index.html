❓ Dúvidas Frequentes

Quem pode enviar uma carta?

Crianças de 1 a 15 anos, com o consentimento e os dados de um responsável.

Quando minha carta chega ao Papai Noel?

Após o envio, a carta é registrada e encaminhada simbolicamente ao Polo Norte. Você receberá uma confirmação na tela.

Meus dados estão seguros?

Sim. Os dados são usados apenas para identificar a carta e o responsável, e não são compartilhados com terceiros. Veja nossa Política de Privacidade.

Posso enviar mais de uma carta?

Sim. Basta preencher o formulário novamente após o envio.

🔒 Política de Privacidade

1. Quais dados coletamos

Coletamos apenas os dados necessários para registrar a cartinha:

  • Nome da criança e idade
  • Nome e telefone do responsável
  • Endereço (CEP, rua, bairro, número, cidade, UF)
  • Texto da cartinha

2. Finalidade

Os dados são usados exclusivamente para identificar a cartinha e permitir que instituições parceiras possam, se desejarem, entrar em contato com o responsável. Não vendemos nem compartilhamos seus dados com terceiros para fins comerciais.

3. Consentimento

O envio só é permitido mediante o consentimento expresso de um responsável maior de 18 anos, marcado no formulário.

4. Armazenamento

Nesta versão do projeto, as cartas são armazenadas localmente no navegador do usuário (localStorage). Nenhum dado é enviado a servidores externos, exceto a consulta de CEP à API pública ViaCEP (que não armazena dados pessoais).

5. Direitos do titular (LGPD)

Conforme a Lei Geral de Proteção de Dados (Lei 13.709/2018), o responsável pode, a qualquer momento:

  • Solicitar acesso aos dados
  • Corrigir dados incompletos ou desatualizados
  • Solicitar a exclusão dos dados
  • Revogar o consentimento

6. Segurança

Adotamos medidas técnicas para proteger os dados, incluindo validação, limitação de exibição pública (apenas nome, cidade, UF e texto da carta são exibidos) e armazenamento local.

7. Contato

Para exercer seus direitos ou tirar dúvidas, entre em contato pelo e-mail: contato@meupedidoparaonatal.com.br
